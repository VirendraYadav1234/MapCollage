# 🗺️ MapCollage

**MapCollage** is a project that provides detailed information about colleges in an organized and easy-to-understand format.

## 📌 Features
- 💰 **Fee Structure** – View college fee details
- 🏫 **Facilities** – Explore facilities offered by each college
- 📍 **College Information** – Access essential academic and campus details

## 🎯 Purpose
The goal of this project is to help users quickly compare colleges and make informed decisions based on available data.
